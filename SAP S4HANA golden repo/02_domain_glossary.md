# SAP S/4HANA Domain Glossary

| Term | Definition |
|---|---|
| Fiori Launchpad (FLP) | Web entry point to SAP apps, organized in spaces, pages, and tiles |
| Business Partner (BP) | Central master record for customers, suppliers, and contacts |
| Sold-to party | Customer who places the order |
| Ship-to party | Customer who receives the goods |
| Bill-to / Payer | Customer who receives the invoice / pays it |
| Product / Material | Master record for goods or services sold, bought, or produced |
| Company code | Smallest legal entity for which financial statements are produced |
| Sales area | Combination of sales organization, distribution channel, and division |
| Plant | Location where goods are produced, stored, or shipped from |
| Storage location | Sub-location of stock within a plant |
| Sales document type | Controls sales document behavior (e.g. OR = Standard Order, CBRE = Returns) |
| Inquiry / Quotation | Pre-sales documents before a sales order |
| Sales order | Customer's binding request for goods or services |
| Outbound delivery | Document that triggers picking, packing, and goods issue |
| Goods issue (GI) | Posting that reduces stock when goods are shipped |
| Billing document | Customer invoice, credit memo, or debit memo |
| Pricing condition | Price, discount, surcharge, or tax element (e.g. PPR0, K004, MWST) |
| ATP | Available-to-Promise check of stock availability |
| Credit block | Block on a document because the customer exceeds credit limits |
| Purchase requisition (PR) | Internal request to procure goods or services |
| Purchase order (PO) | Order sent to a supplier |
| Goods receipt (GR) | Posting that increases stock on receipt from supplier |
| Supplier invoice | Invoice from the supplier, verified against PO and GR (3-way match) |
| GL account | General ledger account in the chart of accounts |
| Journal entry | Financial posting in the Universal Journal (ACDOCA) |
| Document flow | Linked chain of predecessor and successor documents |
| Output management | Generation and sending of forms (PDF, email, EDI) |
| Scope item | SAP Best Practices predefined business process (e.g. BD9 Sell from Stock) |
| Movement type | Code defining a goods movement (e.g. 101 GR, 601 GI) |
