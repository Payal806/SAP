## Launchpad navigation
- Space / page / section

## Screens required
For each screen define:
- Purpose
- Fiori floorplan (List Report, Object Page, Worklist, Overview Page, Wizard)
- Entry points (tile, navigation from another app, deep link)
- Components (header, sections, tables, facets, actions)
- Fields, value helps, and validation
- Loading (busy indicator), empty, success (toast), warning, and error (message popover) states
- Permissions and role / restriction variations
- Accessibility
- Responsive behavior (desktop, tablet, phone)
- Draft handling, if applicable
- Analytics / KPIs
- Navigation and exit conditions

## Important
Follow SAP Fiori design guidelines (Horizon theme). Design only the selected epic and its explicitly linked work items. Do not introduce unrelated capabilities without labeling them as dependencies or assumptions.
