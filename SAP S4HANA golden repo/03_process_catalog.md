# Process Catalog

## Master data
- Create / change Business Partner (customer, supplier)
- Create / change Product (material)
- Maintain pricing conditions
- Maintain credit limits
- Block / unblock Business Partner

## Order to Cash (O2C)
- Create inquiry and quotation
- Create sales order (Sales -> Create Sales Order)
- Change / display sales order
- Availability (ATP) check
- Credit check and release of credit block
- Create outbound delivery
- Picking, packing, and post goods issue
- Create billing document (invoice)
- Post incoming payment and clear receivable
- Returns, credit memo, and debit memo
- Order confirmation and invoice output

## Procure to Pay (P2P)
- Create purchase requisition
- Approve purchase requisition
- Create purchase order
- Post goods receipt
- Create and post supplier invoice (3-way match)
- Handle invoice price / quantity variances
- Execute payment run

## Inventory and warehouse
- Stock overview (single / multiple materials)
- Transfer posting and stock transfer between plants
- Scrapping
- Physical inventory count and posting of differences

## Plan to Produce
- Run MRP
- Convert planned order to production order
- Release production order
- Confirm production and post goods receipt

## Record to Report
- Post general journal entry
- Display GL account balances
- Period-end closing (open/close posting periods)
- Financial statements and trial balance

## Governance
- Business role and catalog assignment
- Segregation of duties review
- Change documents and audit trail
- Data privacy blocking and deletion
- Upgrade regression testing
